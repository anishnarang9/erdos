### Exact method

Script: `contracts/script/provenance.py` (python3 stdlib only, read-only RPC, aborts unless chain ID is 5042002).

1. `arc-forge build` inside WSL (solc 0.8.28, `evm_version = "cancun"`, optimizer off, `via_ir` off, `bytecode_hash` default ipfs, `append_cbor` default true; identical to the `compiler_settings` in Blockscout).
2. Read `deployedBytecode.object` and `deployedBytecode.immutableReferences` from `out/AgenticCommerce.sol/AgenticCommerce.json`. This artifact is the **pristine** file `src/core/src/AgenticCommerce.sol`. The patched copy builds to `out/AgenticCommercePatched.sol/AgenticCommerce.json` and is not compared.
3. `eth_getCode` of the implementation.
4. Strip the CBOR tail from both: `n = last 2 bytes (big-endian)`, drop the last `n + 2` bytes.
5. Zero the `immutableReferences` ranges in both bodies (immutables are filled in at deployment). Print the on-chain value found in each range and check that it equals the implementation address.
6. Byte-compare. Exit 0 on match, 1 on mismatch (prints byte count and first offsets).

Run: `wsl -e bash -lc "cd '/mnt/c/.../UBC-26/contracts' && arc-forge build && python3 script/provenance.py"`. It also runs under Windows python (`python3 -I script/provenance.py`). Options: `--artifact`, `--address`, `--rpc`.

### OpenZeppelin version

The vendored files carry `// OpenZeppelin Contracts (last updated vX)` headers. The highest is **v5.6.0** (`ERC1967Utils`, `ERC165Checker`, `LowLevelCall`, `AccessControl`, `ERC1967Proxy`); others are v5.0.1 to v5.5.0 (per file: last release that changed it). `UPGRADE_INTERFACE_VERSION` on the proxy returns `"5.0.0"` (constant in `UUPSUpgradeable`). So the tree is OpenZeppelin Contracts **5.6.x**. The exact patch release (5.6.0 vs 5.6.1) is UNVERIFIED: the headers do not tell it, and it does not matter because the source is vendored verbatim. `Initializable` and `UUPSUpgradeable` in `openzeppelin-contracts-upgradeable` are 144 and 148 byte re-export shims that import from `@openzeppelin/contracts/proxy/utils/`.
