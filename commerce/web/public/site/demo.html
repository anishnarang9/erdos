    HOW TO READ THE PROOF
    
    
    
      
    Verdict
    1 means every approved check passed. 0 means at least one failed, and a failing proof is never paid.
    
      
    Seal
    A 260-byte Groth16 proof. Arc's verifier contract checks it inside the submit transaction.
    
      
    Envelope hash
    The hash of the encrypted delivery. The buyer's browser checks it before decrypting.
    
      
    Transactions
    Each link opens the Arc testnet explorer, so anyone can confirm the result independently.
