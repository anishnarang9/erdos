## Final test: Flash buyer with solver support

Run one end-to-end attempt only after the readiness gates below pass. Start the buyer in a fresh `agy --model gemini-3.8-flash-low` session. Give it the public service URL, the guide, the test task, and scoped buyer access. Use a separate solver session and wallet. The solver can help the buyer with workflow steps and can use a supplied test receipt. Record the buyer's first blocker, all help, and any supplied deliverable. Keep wallet keys and passwords in protected local files or a scoped signer, never in prompts or logs.

1. **Buyer agent:** Give it one small, supported problem in plain English, declared output and reference files, a funded buyer wallet, and the public buyer guide. It must authenticate, obtain a fresh draft through the hosted API, inspect the generated checks and examples, obtain the required Bot review, approve the exact revision, compile, and fund/register a fresh Arc job. It must publish the job identifier and package/reference links for a solver.
2. **Solver agent:** Give it a separate funded gas wallet, the public solver guide, and the discovery URL. It must find that open job, download and verify the package and references, prepare or use the supplied answer files, run the local check, prepare a fresh proof against the confirmed funded context, claim, release, and confirm its payout. The runner does not create the answer.
3. **Buyer recovery and independent audit:** Recover the exact files from confirmed chain data. Check the result against an independent oracle. Record the job ID, both wallets' before/after balances with gas accounted for, proof and payment receipts, source/package hashes, elapsed proof time, and any intervention. Report buyer help and distinguish the steps the buyer completed on its own. Require a fresh proof and agent-operated settlement. A prewritten rule set does not satisfy fresh authoring.

The test passes only if the two agents complete their own roles through the published API and installed runner, the proof and payout confirm on Arc Testnet, and recovered files match the accepted output. Save a failed attempt as evidence; do not relabel it as a pass after manual repair.
