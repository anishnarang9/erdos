# Shared planning rules

- Read [PLAN.md](PLAN.md) before starting work. It is the shared source of truth for priorities, owners, decisions, and blockers.
- Date every plan entry and substantive revision using `YYYY-MM-DD`. Add the author to each heading. Use a time and timezone when the order of same-day entries matters.
- Keep the latest agreed plan at the top. Preserve prior entries so the team can see what changed and when.
- Mark proposals as proposed. When agreement changes the plan, log the decision, its reason, and the affected owner or next step.
- Keep individual updates in the owner’s `status.md`. Update the shared plan when an individual update changes team scope, ownership, dependencies, or timing.
- Link supporting commits, PRs, or test results when available. Mark pending checks explicitly.
